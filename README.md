# MCP Foundry

**Build, publish, connect and monetize real Model Context Protocol servers.**

MCP Foundry is an independent developer platform in the Noetfield portfolio. It serves external builders and businesses while exposing separately owned Noetfield ventures through consented adapters; it never conflates venture ownership or duplicates their runtime.

This repository is the canonical product, not an umbrella refactor of SourceA, SignalForge, ARQANT, Fieldwork or Founder OS.

## Status

Repository initialized 2026-11-17. A production implementation and deployment are being established. Do not treat planned capabilities as shipped, usage as paying users, or Checkout creation as collected revenue.

See `docs/PRODUCT.md` and `docs/ARCHITECTURE.md` once present for the product contract and rollout architecture.
