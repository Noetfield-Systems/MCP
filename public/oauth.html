HOW PERMISSIONS WORK

A constrained OAuth route.

01 Authenticate to your existing Foundry workspace
02 Approve GitHub's limited user-profile read scope
03 Assign the connection only to a private MCP server
04 Execute HTTPS GET requests only to api.github.com
05 Disconnect locally and revoke remote access in GitHub if needed

GitHub OAuth application credentials must be configured by the Foundry operator before this connector can authorize a user. The presence of this page does not mean a GitHub account is connected. OAuth for arbitrary third-party providers is not enabled here.
