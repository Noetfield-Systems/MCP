ANSWERS THAT MATTER BEFORE YOU CONNECT

Less friction.
More clarity.

What works now, where the boundaries are, and what to expect when you connect a real API.

Is this an active product or a mockup?

The hosted Studio, remote MCP endpoints, authenticated Builder, public directory and official Registry listing are live. We distinguish working software from customer adoption and payments.

Can I start without paying?

Yes. The Free plan supports two servers and ten tools per server, with daily execution limits. A one-time fixed-scope Quickstart has its own live Stripe Payment Link; recurring Pro subscriptions are not enabled until their separate billing configuration is complete.

Can I wrap my existing API?

You can import supported GET operations from OpenAPI JSON or YAML, a local specification file, or a public HTTPS URL. Preview the tools before importing. Arbitrary writes remain unavailable. The GitHub-specific private OAuth connector requires operator setup and user authorization; generic upstream OAuth providers are not connected.

Which AI clients work with Foundry?

Clients supporting remote Streamable HTTP MCP can connect. Exact config and authentication support vary by host; consult Developer Docs for a generic example and official SDK code.

Can I publish a private server?

Yes. Choose Private and attach your personal Foundry bearer key through a supported client. API keys can be revoked.

Does a tool actually call my upstream API?

Yes. GET execution uses protected public-IP HTTPS egress with time and response-size limits. It does not return fabricated successful responses when upstreams fail.

How do I change or disable a published tool?

Editing or removing a tool returns its server to draft. You can republish, unpublish or delete a server from Studio.

Are analytics actual traffic?

Workspace usage is derived from observed invocations. A CI test, directory listing or one tool call is never presented as a paying customer.

Can Noetfield ventures connect without merging?

Yes. They can independently expose approved APIs for Foundry to wrap. Each venture retains its own customers, data, treasury and runtime.

Can your team deliver a custom integration?

Use the implementation enquiry form for a custom scope, or buy the separate public API Quickstart directly through Stripe. The enquiry form itself never charges a payment method.
