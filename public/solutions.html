BUYER QUESTIONS · EXPLICIT SCOPE

Know exactly what you're purchasing.

Start with a real API and a defined use case. The Quickstart is intentionally small; larger integrations are scoped separately.

What qualifies for the CA$199 Public API Quickstart?

One eligible public HTTPS API with up to three read-only GET tools. OAuth, private keys, POST/write actions, multiple unrelated APIs and enterprise SLAs are outside this fixed scope.

What does the buyer actually receive?

A defined MCP tool integration, a real upstream source test or explicit failure, a hosted endpoint when supported, and clear client connection instructions. Customer acceptance and successful paid order records are separate from a website demonstration.

What if my API requires authentication or more than three tools?

Request a scope review through API Agent Launch or the implementation enquiry. Larger/private implementations are individually quoted, not included in Quickstart.

How can I check my API before committing?

Use the free API readiness assessment or start in the existing Builder. A readiness checklist does not guarantee provider compatibility or represent a completed customer integration.
