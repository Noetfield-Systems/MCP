01 / QUICKSTART

From zero to a working endpoint.

01

Register in Studio. Create an account, then select a live-source starter: Hacker News, GitHub public profile or public repository. The starter creates a draft MCP server and its first GET tool.

02

Verify the tool. Open your server’s Test tab and run a real upstream API request. A failed upstream status is reported as a failure rather than a synthetic success.

03

Publish and copy. Publish public or private, then copy the unique HTTPS endpoint at /mcp/your-server. Private endpoints require an account-issued bearer key.

04

Connect an AI client. Use a compatible MCP client with Streamable HTTP. When invoked, real tool-call usage is recorded in your own workspace.

02 / CONNECT

Remote MCP configuration.

Client configuration formats vary. The following is an illustrative generic HTTP MCP configuration; refer to your client’s current documentation for exact fields and authentication support.

PUBLIC DIRECTORY EXAMPLE
{
  "mcpServers": {
    "foundry": {
      "type": "http",
      "url": "https://mcp-foundry-web-production.up.railway.app/mcp/foundry"
    }
  }
}

For private server access and builder tools, create a personal API key in Studio → API keys. Add its Authorization header through the client’s supported credentials configuration. Never put real tokens into public screenshots, GitHub commits or GET URLs.

AUTHENTICATED CLIENT EXAMPLE
{
  "mcpServers": {
    "foundry": {
      "type": "http",
      "url": "https://mcp-foundry-web-production.up.railway.app/mcp/foundry",
      "headers": {
        "Authorization": "Bearer YOUR_PERSONAL_FOUNDRY_API_KEY"
      }
    }
  }
}

04 / OFFICIAL CLIENT SDK

Connect directly from Node.js.

Use the published official MCP client package and a Node.js 22+ environment. This example discovers the anonymous directory tools. For private access, provide a bearer header using your application’s secret handling.

NODE.JS · STREAMABLE HTTP
import {Client, StreamableHTTPClientTransport}
  from '@modelcontextprotocol/client';

const client = new Client({
  name: 'my-foundry-client',
  version: '1.0.0'
});
const transport = new StreamableHTTPClientTransport(
  new URL('https://mcp-foundry-web-production.up.railway.app/mcp/foundry')
);

try {
  await client.connect(transport);
  const {tools} = await client.listTools();
  console.log(tools.map(tool => tool.name));
} finally {
  await client.close();
}
